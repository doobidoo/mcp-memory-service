- **Context injection can exclude consolidation meta-beliefs via `MCP_INJECT_EXCLUDE_TYPES`.** Consolidation emits meta-beliefs whose content is prefixed `[GAP]`, `[PATTERN]`, `[TREND]` (analysis *about* the corpus). These are useful in a dashboard but crowd out real knowledge in conversational context injection. Set `MCP_INJECT_EXCLUDE_TYPES=gap,pattern` (comma-separated insight_types) to drop them from injection; unset is a no-op (back-compatible). They remain in the store — only injection skips them.
