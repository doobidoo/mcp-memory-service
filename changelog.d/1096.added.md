- **Per-agent MCP tool-call rate limiting (#1096).** `call_tool` now has an optional thread-safe sliding-window limiter keyed by agent identity (with a bounded connection/session fallback), so one batch agent cannot starve interactive agents. `MCP_RATE_LIMIT_PER_MINUTE` sets the default per-tool limit, `MCP_RATE_LIMIT_<tool>` overrides a specific tool, and unset or `0` preserves unlimited behavior. Denied calls return a standard MCP `isError` result with retry metadata.
