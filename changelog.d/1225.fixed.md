- **Alive memories can no longer be committed without their embedding row (#1225).** `store()` serializes its savepoint + commit under `_savepoint_lock`, but the delete and metadata mixins committed the shared SQLite connection without that lock. A commit landing between another path's open SAVEPOINT and its RELEASE persisted the `memories` row alone — exactly the 71 silent orphans found in production: invisible to semantic search while still counted by tag and time queries. Every mutating path now goes through `_execute_write`, which holds the same lock; a regression test injects a foreign commit mid-savepoint and asserts the orphan count stays zero.
