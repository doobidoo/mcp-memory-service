**Performance**: Add `candidate_hashes` parameter to `get_access_patterns()` to enable scoped access pattern queries instead of loading all accessed memories. Fixes unbounded query performance issue introduced by removal of LIMIT 100 in #1288.

The new parameter maintains backward compatibility (defaults to `None` for current behavior) and allows consolidation processes to query only the candidate memories they need to evaluate, significantly reducing memory usage and query time for large databases.
