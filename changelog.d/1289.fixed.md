- **Scoped `get_access_patterns()` to the consolidation candidate window (#1294, closes #1289).**
  Removing the `LIMIT 100` in #1288 left the query unbounded — every consolidation run
  loaded all ever-accessed memories, though decay and forgetting only look up the current
  bounded batch. `get_access_patterns()` now takes an optional `candidate_hashes`: `None`
  keeps the full query (backward-compatible), a list filters via a chunked, parameterized
  `WHERE content_hash IN (...)`, and an empty list returns `{}`. The consolidator passes the
  batch hashes; `hybrid` delegates; `milvus` filters its drained records in memory.
