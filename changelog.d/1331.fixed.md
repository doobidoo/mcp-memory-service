- **A tag with a space in it could not be found or deleted on sqlite-vec (#1331).**
  Tag queries compare against the stored tags with spaces removed, but only
  `retrieve()` (#1189) removed them from the searched tag, so `machine learning`
  matched nothing in tag search, `list_memories`, the tag counts or the four tag
  deletes. Every tag query now removes spaces from the searched tag too.
