- A hybrid hub no longer pulls back what it forwarded to its secondary (#1506, part 2). Cloudflare stamps a forwarded edit or delete with the time of the forward, so the next pull read it as a newer remote change: the drift scan re-applied the edit on the hub, and a forwarded delete could remove a memory a spoke had re-created in the meantime. The pull now skips a row or tombstone whose stamp is not later than the hub's own forward of that hash (`secondary_forwarded`); a later change made on Cloudflare by another machine still applies.
