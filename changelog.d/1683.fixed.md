- **Store-scoped operations stay within the requested memory store (#1683).** Search, on-store NLI, hash-addressed writes, entity-graph reads, bootstrap profiles, and MCP resources carry the store through storage predicates; scoped NLI quarantines/counts only within that store and does not mutate unpartitioned global belief state. Backends without proven partition support fail closed instead of exposing data from another store. Store-scoped analytics also omit the backend-wide database file size; the global all-store view retains it.
