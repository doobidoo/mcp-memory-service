- **Tag-only and time-only search and `memory_list` returned superseded versions (#1803).**
  On sqlite-vec, `memory_search` without a `query` (tags or time only), exact mode, and
  `memory_list` built their results without going through `retrieve()`, so the old versions
  left behind by `memory_update` with `versioned: true` came back as if current, while the
  same search with a query hid them. These paths now hide superseded versions unless
  `include_superseded` or `as_of` asks for them, and `memory_list` totals and pages count
  current versions only. `get_all_memories()` keeps every live row by default for sync,
  export and maintenance callers.
