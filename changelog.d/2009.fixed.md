- **Starting a document upload no longer covers the dashboard with the loading overlay (#2009).**
  `handleDocumentUpload()` blocked the whole page with `setLoading(true)` although the
  status island already reports imports. It now reports the transfer to the island as a
  busy "Documents" source, disables the upload button while the request runs and ignores
  a second trigger. The overlay stays on the other `setLoading` call sites, which the
  island does not report.
- **Document removal and the bulk operations no longer cover the dashboard with the
  loading overlay (#2009).** `removeDocument()` and the four Manage bulk operations now
  report busy to the status island on their existing sources, clear the entry on success
  and keep their failure there, disable the triggering button while the request runs and
  rely on it instead of `setLoading(true)`. The overlay stays on the view loads, search,
  the document viewer and ontology writes, which the island does not report.
