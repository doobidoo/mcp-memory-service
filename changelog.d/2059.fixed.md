- **Cloudflare time-only recall and memory timestamps no longer count deleted memories (#2059).**
  Both readers queried the tombstoned `memories` rows without `deleted_at IS NULL`. By-time
  searches (`POST /api/search/by-time`) returned memories the user had deleted, and the analytics
  endpoints counted them in memory growth, activity heatmap, and activity breakdown. The four
  affected D1 statements now exclude tombstones, matching the semantic branch and
  `get_memories_by_time_range()`.
