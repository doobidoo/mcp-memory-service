- **Cloudflare memory timestamps no longer count soft-deleted memories (#2059).**
  `_fetch_d1_timestamps()` queried tombstoned `memories` rows in both the cutoff and no-cutoff
  paths, so analytics endpoints (memory growth, activity heatmap, activity breakdown) counted
  memories the user had deleted. Both D1 statements now filter `deleted_at IS NULL`, matching
  the time-only `recall()` paths and `get_memories_by_time_range()`.
