- **The OpenCode plugin can own the memory service's lifecycle (`memoryService.autoStart`, off by default, #2088).**
  A local service had to be started by hand, systemd, launchd or a Startup entry, and
  it outlived the editor. `autoStart` now starts `command` when OpenCode starts,
  reuses an endpoint that is already reachable instead of starting a second
  instance, and stops the process it started when the plugin is disposed
  (`taskkill /T` on Windows, `SIGTERM` to the process group on POSIX).
  `startTimeoutMs` keeps a slow server from blocking the first session, and
  `OPENCODE_MEMORY_AUTOSTART=1` enables the feature without a configuration file.
