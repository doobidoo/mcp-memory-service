- **Auto-capture and session summaries stored Claude Code's own injected text as the user's prompt (#2149).**
  `parseTranscript` in `auto-capture-hook.js` and `session-end.js` took the nearest `user`-role
  transcript entry as the prompt, skipping only tool results. Claude Code also writes
  `<system-reminder>` blocks, background-task notifications, messages from other sessions and
  compaction summaries under that role, so they were captured as "User: ..." and fed to the
  `#skip`/`#remember` check. A shared `utilities/transcript-filter.js` now strips
  `<system-reminder>` spans, skips attachments (`isMeta`, reminder-only, local command output) while
  scanning back, and stops at entries that start a turn of their own (non-`human` `origin.kind`,
  notification prefixes, compaction summaries) so a reply to a notification is not paired with an older
  prompt. Auto-capture skips a turn that has no typed prompt instead of storing "[no message]".
