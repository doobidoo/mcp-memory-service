- **Exiting and resuming one Claude Code session stored a new "Session Summary" every time, and Cargo workspace roots were named `rust-project` (#2150).**
  The SessionEnd hook now records `session_id` (metadata and a `sys:claude-session:<id>` tag), skips the
  write when the transcript has not grown since the stored summary, and otherwise updates that summary via
  `PUT /api/memories/{hash}`; a failed lookup stores as before. Manifests without a name no longer yield
  placeholder project names (`rust-project`, `node-project`, ...), so the git repository or directory
  name is used; memories already tagged with a placeholder keep it.
