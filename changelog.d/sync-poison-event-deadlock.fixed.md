Delta-sync no longer deadlocks on "poison" events. A create whose content is empty in both the event payload and the source table is now treated as skippable (the orchestrator advances past it instead of fail-stopping the whole feed), the feed stops clobbering a payload's good content with an empty table value, and the push ingest classifies anti-replay payload-divergence rejections as skipped_duplicate so a single divergent event cannot block the entire push backlog. Anti-replay protection is unchanged — a divergent payload still never rewrites the stored memory.
