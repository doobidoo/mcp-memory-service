MCP Memory Service

Ein dauerhaftes Gedächtnis für deine KI-Assistenten

Projektentscheidungen, Präferenzen und Lösungen sollen auch in der nächsten Sitzung verfügbar sein. MCP Memory Service speichert dieses Wissen auf deinem eigenen System und macht es für Claude Code und andere KI-Assistenten durchsuchbar.

Beispiel für deinen AI-Client

Heute speichern

„Merke dir für dieses Projekt: Wir verwenden PostgreSQL und testen mit pytest.“

In der nächsten Sitzung abrufen

„Welche Datenbank und welche Tests verwenden wir in diesem Projekt?“

Dein Client muss die Memory-Werkzeuge zum Speichern und Abrufen aufrufen. Diese Sätze sind Beispiele, keine festen Befehle.

Projektwissen behalten, statt es immer neu zu erklären

Ein gemeinsamer Wissensspeicher für deine Arbeit mit KI-Assistenten, erreichbar über MCP, REST API oder CLI.

Entscheidungen wiederfinden

Halte fest, warum du eine Bibliothek gewählt oder eine Architektur geändert hast. Rufe die Begründung später ab, ohne alte Chatverläufe zu durchsuchen.

Nach Bedeutung suchen

Finde gespeicherte Lösungen auch dann, wenn deine Frage andere Wörter verwendet. Tags helfen dabei, die Suche auf ein Projekt oder Thema einzugrenzen.

Selbst hosten

Starte lokal mit SQLite und Vektorsuche. Für diesen Betrieb brauchst du weder einen Cloud-Speicherdienst noch einen kostenpflichtigen Embedding-API-Schlüssel.

In Claude Code einrichten

Du brauchst Python 3.10 oder neuer und einen installierten Claude-Code-Client. Andere Clients lassen sich ebenfalls über MCP anbinden; die englische Anleitung beschreibt die Konfiguration.

  1. Memory Service installieren

    pip install 'mcp-memory-service[sqlite]'

    Installiere das Paket in einer Python-Umgebung, deren Befehle für deinen Client erreichbar sind.

  2. Als MCP-Server hinzufügen

    claude mcp add memory -- memory server

    Führe den Befehl im Projektverzeichnis aus und starte Claude Code danach neu. Beim ersten Start wird das lokale Embedding-Modell heruntergeladen.

  3. Eine erste Erinnerung speichern

    Bitte deinen Client, eine Projektpräferenz zu speichern. Prüfe den erfolgreichen Werkzeugaufruf und frage in einer neuen Sitzung danach. So lässt sich prüfen, ob Speichern und Abrufen funktionieren.

Häufige Fragen

Speichert der Service automatisch jeden Chat?

Die MCP-Anbindung allein speichert nicht automatisch jede Unterhaltung. Dein Client muss die Werkzeuge verwenden. Optionale Hooks und Funktionen für den Import von Sitzungen haben eine eigene Einrichtung.

Bleiben meine Erinnerungen lokal?

Beim lokalen SQLite-Betrieb werden die Erinnerungen auf deinem System gespeichert und Embeddings lokal berechnet. Welche Daten dein AI-Client an seinen Modellanbieter sendet, hängt vom Client ab. Cloudflare-Speicher und Synchronisation sind optionale Konfigurationen.

Funktioniert das nur mit Claude?

Nein. Neben MCP stellt der Service eine REST API und eine CLI bereit. Du kannst auch andere kompatible Clients und eigene Anwendungen anbinden.

Ist MCP Memory Service kostenlos?

Der Service ist Open Source unter der Apache-2.0-Lizenz. Du kannst ihn selbst betreiben. Kosten für deinen AI-Client, Hosting oder optionale externe Dienste fallen gegebenenfalls separat an.
