Aloja el servicio en tu equipo

Empieza en local con SQLite y búsqueda vectorial. Para esta configuración no necesitas almacenamiento en la nube ni una API de pago para generar embeddings.

Configúralo en Claude Code

Necesitas Python 3.10 o posterior y tener instalado Claude Code. También puedes conectar otros clientes mediante MCP; la guía en inglés explica cómo configurarlos.

  1. Instala Memory Service

    pip install 'mcp-memory-service[sqlite]'

    Instala el paquete en un entorno de Python cuyos comandos estén disponibles para tu cliente.

  2. Añádelo como servidor MCP

    claude mcp add memory -- memory server

    Ejecuta el comando desde el directorio del proyecto y reinicia Claude Code. En el primer inicio se descargará el modelo local de embeddings.

  3. Guarda tu primer recuerdo

    Pide a tu cliente que guarde una preferencia del proyecto. Comprueba que la llamada a la herramienta se haya completado correctamente y pregunta por esa preferencia en una nueva sesión. Así podrás verificar que la información se guarda y se recupera.

Preguntas frecuentes

¿El servicio guarda automáticamente todas las conversaciones?

Conectar el servicio mediante MCP no guarda automáticamente todas las conversaciones. Tu cliente debe usar las herramientas. Los hooks opcionales y las funciones de importación de sesiones requieren su propia configuración.

¿Mis recuerdos se quedan en mi equipo?

Con la configuración local de SQLite, los recuerdos se guardan en tu sistema y los embeddings se calculan localmente. Los datos que tu cliente de IA envíe al proveedor del modelo dependen del propio cliente. El almacenamiento en Cloudflare y la sincronización son opciones que se configuran por separado.

¿Solo funciona con Claude?

No. Además de MCP, el servicio ofrece una API REST y una CLI. Puedes conectar otros clientes compatibles y tus propias aplicaciones.

¿MCP Memory Service es gratuito?

El servicio es de código abierto y se distribuye bajo la licencia Apache 2.0. Puedes alojarlo tú mismo. Tu cliente de IA, el alojamiento y los servicios externos opcionales pueden tener costes adicionales.
