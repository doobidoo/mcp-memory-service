MCP Memory Service

Une mémoire persistante pour vos assistants IA

Les décisions, préférences et solutions d'un projet devraient rester disponibles d'une session à l'autre. MCP Memory Service enregistre ces connaissances sur votre propre système, pour que Claude Code et d'autres assistants IA puissent les consulter.

Exemple pour votre client IA

Enregistrez aujourd'hui

« Retiens que dans ce projet, nous utilisons PostgreSQL et que nous testons avec pytest. »

Retrouvez à la session suivante

« Quelle base de données et quel outil de test utilisons-nous dans ce projet ? »

Votre client doit appeler les outils de mémoire pour enregistrer et retrouver les informations. Ces phrases sont des exemples, pas des commandes fixes.

Gardez le contexte de votre projet sans devoir le réexpliquer

Une base de connaissances partagée pour travailler avec des assistants IA, accessible via MCP, l'API REST ou la CLI.

Retrouvez vos décisions

Notez pourquoi vous avez choisi une bibliothèque ou modifié l'architecture. Retrouvez l'explication plus tard sans fouiller dans d'anciennes conversations.

Cherchez par le sens

Retrouvez des solutions enregistrées même si vous formulez la question autrement. Les étiquettes permettent de limiter la recherche à un projet ou à un sujet.

Hébergez le service sur votre machine

Commencez en local avec SQLite et la recherche vectorielle. Cette configuration ne nécessite ni stockage dans le cloud ni API payante pour générer les embeddings.

Configurez-le dans Claude Code

Il vous faut Python 3.10 ou une version ultérieure, ainsi que Claude Code installé. Vous pouvez aussi connecter d'autres clients via MCP ; le guide en anglais explique comment les configurer.

  1. Installez Memory Service

    pip install 'mcp-memory-service[sqlite]'

    Installez le paquet dans un environnement Python dont les commandes sont accessibles à votre client.

  2. Ajoutez-le comme serveur MCP

    claude mcp add memory -- memory server

    Lancez la commande depuis le répertoire du projet, puis redémarrez Claude Code. Au premier démarrage, le modèle local d'embeddings est téléchargé.

  3. Enregistrez votre premier souvenir

    Demandez à votre client d'enregistrer une préférence du projet et vérifiez que l'appel à l'outil a abouti. Interrogez-le ensuite sur cette préférence dans une nouvelle session : vous confirmez ainsi que l'information est enregistrée puis retrouvée.

Questions fréquentes

Le service enregistre-t-il automatiquement toutes les conversations ?

Non. Connecter le service via MCP ne suffit pas : votre client doit appeler les outils de mémoire. Les hooks optionnels et l'import de sessions nécessitent leur propre configuration.

Mes souvenirs restent-ils sur ma machine ?

Avec la configuration SQLite locale, les souvenirs sont stockés sur votre système et les embeddings sont calculés localement. Les données que votre client IA envoie au fournisseur du modèle dépendent du client lui-même. Le stockage Cloudflare et la synchronisation sont des options qui se configurent séparément.

Le service fonctionne-t-il uniquement avec Claude ?

Non. En plus de MCP, le service propose une API REST et une CLI. Vous pouvez connecter d'autres clients compatibles ainsi que vos propres applications.

MCP Memory Service est-il gratuit ?

Le service est open source et distribué sous licence Apache 2.0. Vous pouvez l'héberger vous-même. Votre client IA, l'hébergement et les services externes optionnels peuvent entraîner des coûts supplémentaires.
