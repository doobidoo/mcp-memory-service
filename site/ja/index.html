MCP Memory Service

AIアシスタントに永続的なメモリーを

プロジェクトの決定事項、設定、解決策を次のセッションでもそのまま使えるように。MCP Memory Serviceはこうした知識をあなた自身のシステムに保存し、Claude CodeをはじめとするAIアシスタントから検索できるようにします。

セットアップを始める GitHubでプロジェクトを見る

AIクライアントへの依頼例

今日保存する

「このプロジェクトではPostgreSQLを使っていて、テストはpytestで行っていると覚えておいて。」

次のセッションで呼び出す

「このプロジェクトで使っているデータベースとテストフレームワークを教えて。」

保存も呼び出しも、クライアントがメモリーツールを呼び出す必要があります。これらの文は依頼の例であり、固定のコマンドではありません。

プロジェクトの知識を、毎回説明し直すのではなく残しておく

AIアシスタントとの作業のための共通の知識ベース。MCP、REST API、CLIから利用できます。

決定事項を再び見つける

ライブラリを選んだ理由やアーキテクチャを変更した経緯を記録。後から根拠を呼び出せるので、古いチャット履歴を探し回る必要はありません。

意味で検索する

質問に使った言葉が違っても、保存してある解決策を見つけられます。タグを使えばプロジェクトやテーマに検索を絞り込めます。

セルフホストで運用

SQLiteとベクトル検索でローカルに始められます。クラウドのストレージサービスも有償のEmbedding APIキーも不要です。

Claude Codeにセットアップする

Python 3.11以降と、インストール済みのClaude Codeクライアントが必要です。他のクライアントもMCP経由で接続できます。設定方法は英語のガイドに記載されています。

  1. Memory Serviceをインストール

    pip install 'mcp-memory-service[sqlite]'

    クライアントからコマンドを利用できるPython環境に、パッケージをインストールします。

  2. MCPサーバーとして追加

    claude mcp add memory -- memory server

    プロジェクトのディレクトリでコマンドを実行し、Claude Codeを再起動してください。初回起動時にローカルのEmbeddingモデルがダウンロードされます。

  3. 最初のメモリーを保存

    クライアントにプロジェクトの設定を保存するよう依頼します。ツール呼び出しが成功したことを確認し、新しいセッションで同じ内容を質問してみてください。保存と呼び出しが両方動くことを確認できます。

よくある質問

チャットは自動的にすべて保存されますか？

MCP接続だけで会話が自動保存されることはありません。クライアントがツールを使用する必要があります。セッション取り込み用のオプションのフックや機能には、それぞれ個別のセットアップがあります。

メモリーは手元に残りますか？

ローカルSQLite構成では、メモリーはあなたのシステムに保存され、Embeddingもローカルで計算されます。AIクライアントがモデルプロバイダーへ送るデータはクライアント側の挙動に依存します。Cloudflareストレージと同期はオプション設定です。

Claudeでしか使えませんか？

いいえ。MCPに加えて、REST APIとCLIも提供しています。他の互換クライアントや自作アプリケーションも接続できます。

MCP Memory Serviceは無料ですか？

このサービスはApache-2.0ライセンスのオープンソースで、自分でホストして利用できます。AIクライアントの利用料、ホスティング、オプションの外部サービスの費用は別途かかる場合があります。
