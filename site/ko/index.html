MCP Memory Service

AI 어시스턴트에게 오래 남는 기억을

프로젝트의 결정 사항, 설정, 해결 방법을 다음 세션에서도 활용하세요. MCP Memory Service는 이 지식을 사용자의 시스템에 저장하여 Claude Code와 다른 AI 어시스턴트가 검색할 수 있게 합니다.

오늘 저장하고

“이 프로젝트에서는 PostgreSQL을 사용하고 pytest로 테스트한다는 것을 기억해 줘.”

다음 세션에서 불러오세요

“이 프로젝트에서 사용하는 데이터베이스와 테스트 도구가 뭐야?”

저장하고 불러오려면 클라이언트가 메모리 도구를 호출해야 합니다. 위 문장은 요청 예시이며 정해진 명령어가 아닙니다.

매번 다시 설명하지 말고 프로젝트 지식을 보관하세요

AI 어시스턴트와 함께 작업할 때 사용할 공통 지식 저장소입니다. MCP, REST API, CLI로 접근할 수 있습니다.

결정의 이유를 다시 확인하세요

라이브러리를 선택하거나 아키텍처를 변경한 이유를 기록하세요. 나중에 오래된 대화를 뒤질 필요 없이 그 근거를 불러올 수 있습니다.

의미로 검색하세요

다른 표현으로 질문해도 저장한 해결 방법을 찾을 수 있습니다. 태그를 사용하면 특정 프로젝트나 주제로 검색 범위를 좁힐 수 있습니다.

직접 호스팅하세요

SQLite와 벡터 검색으로 로컬에서 시작하세요. 이 구성에는 클라우드 저장소 서비스나 유료 임베딩 API 키가 필요하지 않습니다.

Claude Code에서 설정하기

Python 3.11 이상과 설치된 Claude Code 클라이언트가 필요합니다. 다른 클라이언트도 MCP로 연결할 수 있으며, 설정 방법은 영어 가이드에서 확인할 수 있습니다.

  1. Memory Service 설치

    pip install 'mcp-memory-service[sqlite]'

    클라이언트에서 명령어를 실행할 수 있는 Python 환경에 패키지를 설치하세요.

  2. MCP 서버로 추가

    claude mcp add memory -- memory server

    프로젝트 디렉터리에서 명령어를 실행한 뒤 Claude Code를 다시 시작하세요. 처음 실행할 때 로컬 임베딩 모델이 다운로드됩니다.

  3. 첫 메모리 저장

    클라이언트에 프로젝트 규칙을 저장해 달라고 요청하세요. 도구 호출이 성공했는지 확인한 뒤 새 세션에서 그 규칙을 물어보세요. 저장과 검색이 모두 작동하는지 확인할 수 있습니다.

자주 묻는 질문

모든 대화가 자동으로 저장되나요?

MCP로 연결하는 것만으로 모든 대화가 자동 저장되지는 않습니다. 클라이언트가 메모리 도구를 사용해야 합니다. 선택 사항인 훅과 세션 가져오기 기능은 별도로 설정해야 합니다.

메모리는 제 시스템에 보관되나요?

로컬 SQLite 구성에서는 메모리가 사용자의 시스템에 저장되고 임베딩도 로컬에서 계산됩니다. AI 클라이언트가 모델 제공업체에 어떤 데이터를 보내는지는 해당 클라이언트에 따라 다릅니다. Cloudflare 저장소와 동기화는 별도로 설정하는 선택 사항입니다.

Claude에서만 사용할 수 있나요?

아니요. MCP 외에도 REST API와 CLI를 제공합니다. 다른 호환 클라이언트나 직접 만든 애플리케이션에서도 연결할 수 있습니다.

MCP Memory Service는 무료인가요?

이 서비스는 Apache-2.0 라이선스의 오픈 소스이며 직접 호스팅하여 사용할 수 있습니다. AI 클라이언트, 호스팅, 선택적인 외부 서비스에는 별도 비용이 발생할 수 있습니다.
