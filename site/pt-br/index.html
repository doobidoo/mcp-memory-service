MCP Memory Service

Memória persistente para os seus assistentes de IA

As decisões, as preferências e as soluções de um projeto também deveriam estar à mão na próxima sessão. O MCP Memory Service guarda esse conhecimento no seu próprio sistema, para que o Claude Code e outros assistentes de IA possam consultá-lo.

Hospede no seu próprio ambiente

Comece localmente com SQLite e busca vetorial. Essa configuração não exige serviço de armazenamento na nuvem nem chave paga de API de embeddings.

Configurar no Claude Code

Você precisa do Python 3.11 ou mais recente e do Claude Code instalado. Outros clientes também podem se conectar por MCP; o guia em inglês explica como configurá-los.

  1. Instale o Memory Service

    pip install 'mcp-memory-service[sqlite]'

    Instale o pacote em um ambiente Python cujos comandos estejam disponíveis para o seu cliente.

  2. Adicione como servidor MCP

    claude mcp add memory -- memory server

    Execute o comando no diretório do projeto e reinicie o Claude Code. Na primeira execução, o modelo local de embeddings é baixado.

  3. Guarde a sua primeira memória

    Peça ao seu cliente para guardar uma convenção do projeto. Confirme que a chamada da ferramenta foi concluída e pergunte por essa convenção em uma nova sessão. Assim você verifica que guardar e recuperar funcionam.

Perguntas frequentes

Todas as conversas são guardadas automaticamente?

Conectar o serviço por MCP não guarda automaticamente todas as conversas: o seu cliente precisa usar as ferramentas. Os hooks opcionais e os recursos de importação de sessões têm configuração própria.

As memórias ficam no meu ambiente?

Na configuração local com SQLite, as memórias ficam guardadas no seu sistema e os embeddings são calculados localmente. Os dados que o seu cliente de IA envia ao provedor do modelo dependem do próprio cliente. O armazenamento no Cloudflare e a sincronização são opções configuradas separadamente.

Funciona só com o Claude?

Não. Além do MCP, o serviço oferece uma API REST e uma CLI. Você pode conectar outros clientes compatíveis e as suas próprias aplicações.

O MCP Memory Service é gratuito?

O serviço é de código aberto, sob a licença Apache 2.0, e você pode hospedá-lo por conta própria. O seu cliente de IA, a hospedagem e os serviços externos opcionais podem ter custos adicionais.
