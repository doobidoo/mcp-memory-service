MCP Memory Service

为你的 AI 助手配上持久记忆

项目里的决定、偏好和解决方案，在下一次会话里也该随手可得。MCP Memory Service 把这些知识保存在你自己的系统上，让 Claude Code 等 AI 助手可以随时检索。

开始配置 在 GitHub 上查看项目

向 AI 客户端提问的示例

今天先存下来

“记住：这个项目用 PostgreSQL，测试用 pytest。”

下次会话里取回来

“这个项目用的是哪个数据库，测试工具是什么？”

保存和检索都需要客户端去调用记忆工具。上面这些句子只是提问示例，并不是固定的命令。

把项目知识留下来，不必每次重新交代一遍

与 AI 助手协作时共用的一份知识库，可以通过 MCP、REST API 或命令行访问。

找回当初的决定

记下为什么选了某个库、为什么改了架构。以后直接检索当初的理由，不用再翻旧的聊天记录。

按语义检索

即使换一种说法提问，也能找到已经存下的解决方案。用标签可以把检索范围缩小到某个项目或主题。

放在自己的机器上运行

用 SQLite 加向量检索就能在本地起步。这种配置既不需要云存储服务，也不需要付费的 Embedding API 密钥。

在 Claude Code 中配置

需要 Python 3.11 或更高版本，以及已经装好的 Claude Code 客户端。其他客户端也可以通过 MCP 接入，配置方法见英文指南。

  1. 安装 Memory Service

    pip install 'mcp-memory-service[sqlite]'

    把这个包安装到客户端能够调用其命令的 Python 环境里。

  2. 添加为 MCP 服务器

    claude mcp add memory -- memory server

    在项目目录下执行这条命令，然后重启 Claude Code。首次启动时会下载本地 Embedding 模型。

  3. 保存第一条记忆

    让客户端存下一条项目里的约定。确认工具调用成功之后，在一个新会话里再问一次这条约定，就能验证保存和检索都正常。

常见问题

会自动保存所有聊天内容吗？

仅仅通过 MCP 接上服务，并不会自动保存全部对话，还需要客户端去调用工具。可选的钩子和会话导入功能各有自己的配置步骤。

记忆会留在我自己的机器上吗？

在本地 SQLite 配置下，记忆保存在你自己的系统上，Embedding 也在本地计算。至于 AI 客户端向模型提供方发送了哪些数据，取决于客户端本身的行为。Cloudflare 存储和同步都是需要另行配置的可选项。

只能和 Claude 一起用吗？

不是。除了 MCP，服务还提供 REST API 和命令行。其他兼容的客户端以及你自己写的应用都可以接入。

MCP Memory Service 是免费的吗？

服务以 Apache 2.0 许可证开源，可以自行部署。AI 客户端的使用费、托管费用以及可选的外部服务，都可能产生额外成本。
