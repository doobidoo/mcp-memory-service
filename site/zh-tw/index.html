MCP Memory Service

讓你的 AI 助理記得住

專案裡做過的決定、偏好和解法，下一次對話也該找得到。MCP Memory Service 把這些知識存在你自己的系統上，讓 Claude Code 等 AI 助理隨時可以搜尋。

開始設定 到 GitHub 看專案

對 AI 用戶端提問的範例

今天先存起來

「記住：這個專案用 PostgreSQL，測試用 pytest。」

下次對話再找回來

「這個專案用哪個資料庫？測試工具是什麼？」

存入和找回都要由用戶端呼叫記憶工具。上面這些句子只是提問範例，不是固定指令。

專案知識留下來，不必每次從頭交代

你和 AI 助理共用的一份知識庫，可以透過 MCP、REST API 或命令列存取。

找回當初的決定

記下為什麼選了某個函式庫、為什麼改了架構。之後直接搜尋當時的理由，不用再翻舊的對話紀錄。

用語意搜尋

就算換個說法問，也能找到之前存下的解法。加上標籤，就能把搜尋範圍縮小到某個專案或主題。

在自己的電腦上執行

用 SQLite 加向量搜尋就能在本機開始使用。這種設定不需要雲端儲存服務，也不需要付費的 Embedding API 金鑰。

在 Claude Code 中設定

需要 Python 3.11 以上版本，以及已安裝的 Claude Code 用戶端。其他用戶端也能透過 MCP 連接，設定方式請看英文指南。

  1. 安裝 Memory Service

    pip install 'mcp-memory-service[sqlite]'

    把套件安裝到用戶端能執行其指令的 Python 環境。

  2. 加入為 MCP 伺服器

    claude mcp add memory -- memory server

    在專案目錄執行這行指令，然後重新啟動 Claude Code。第一次啟動時會下載本機的 Embedding 模型。

  3. 存入第一筆記憶

    請用戶端存下一條專案慣例。確認工具呼叫成功後，開一個新對話再問一次這條慣例，就能確認存入和找回都正常。

常見問題

會自動存下所有對話內容嗎？

只透過 MCP 連上服務，並不會自動存下整段對話，還要由用戶端呼叫工具。選用的 hook 和對話匯入功能各有自己的設定步驟。

記憶會留在我自己的電腦上嗎？

使用本機 SQLite 設定時，記憶存在你自己的系統上，Embedding 也在本機計算。AI 用戶端會把哪些資料送給模型供應商，取決於用戶端本身。Cloudflare 儲存與同步都是要另外設定的選項。

只能搭配 Claude 使用嗎？

不是。除了 MCP，服務也提供 REST API 和命令列。其他相容的用戶端和你自己寫的應用程式都能連接。

MCP Memory Service 是免費的嗎？

服務以 Apache 2.0 授權開源，可以自行架設。AI 用戶端的使用費、主機費用以及選用的外部服務，都可能產生額外成本。
